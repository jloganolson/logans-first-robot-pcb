Archived v0.6 review

The archived v0.6 board uses an external mechanical switch with two separate power contacts operated by one handle. Four heavy wires connect it to J5. Stop the robot first, then switch OFF. There is no software supervisor or automatic stop sequence.

Open the v0.6 wiring, changes, checks and commissioning walkthrough →

Both battery positives disconnect before they join the board's shared supply. The negatives stay connected. ON directly parallels the batteries, so equalization/reconnect must be qualified before using two real packs. USB can still power the USB section with the battery switch OFF.

The revised layout replaces the provisional PCB switch and 32 V fuse holders, uses soldered power pigtails, upgrades and splits the servo sockets, adds controlled USB power turn-on, and specifies the USB layer stackup. Automated results and the exact order status appear in the linked walkthrough.
